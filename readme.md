# web-lite-tabletop-sim

自托管的轻量级 2D 网页虚拟桌面（VTT）。朋友**不用装任何客户端**，
老旧低配手机打开浏览器就能连上同一张桌子。

没有规则判定 —— 它是一个**纯沙盒**：翻面、旋转、移动、掷骰、标记，
都交给你和你的朋友，就像一张真实的桌子。

## 特性

| | |
|---|---|
| **零安装** | 浏览器打开即可。没有 App、没有账号、没有注册 |
| **双盲** | 房主划「视野区」，指定哪支队伍能看见。服务端裁剪，不是前端遮挡 |
| **真实资产** | 自带 TTS（Tabletop Simulator）存档转换工具，把 Steam 创意工坊的现成模组变成 2D 盘面 |
| **无限地图** | 浮点坐标、无网格、无边界。想摆多远摆多远 |
| **骰子** | d2 / d4 / d6 / d10 / d12，带抛物动画。点数由**服务端**掷（同桌的人看到同一个数） |
| **标记** | 方形 / 圆形 / 三角形 / 星形 / 可输入文字的文字框，都能自定义颜色 |
| **存档** | base64 文本，复制粘贴就能分享。不写文件 |
| **低配优先** | 双层 Canvas + 按需重绘 + LOD 色块 + 按字节预算的贴图缓存 |

## 快速开始

```bash
git clone <this-repo>
cd web-lite-tabletop-sim
npm install          # 依赖只有 ws 一个
npm start            # http://localhost:3000
```

> **注意**：仓库里**不含贴图**（1003 张 WebP，13MB）。
> 不跑资产管线也能启动，但棋盘上的棋子会是空白 ——
> 见下面的「资产」一节。

用 Docker 部署见 [DOCKER.md](DOCKER.md)。

### 怎么玩

1. 打开首页，填个昵称
2. **创建房间** → 拿到 6 位邀请码（如 `XK3F9Q`）
3. 把 `http://<你的IP>:3000/room.html?room=XK3F9Q` 发给朋友
4. 房主在右上角给每人分配队伍（红 / 蓝 / 旁观）
5. 房主点「视野区」划一块区域，选哪支队伍能看见

局域网里朋友访问，需要你把地址换成**本机内网 IP**（不是 `localhost`）。
服务端默认监听 `0.0.0.0`，所以防火墙放行端口即可。

## 资产

**贴图不在仓库里**（版权原因 + 体积）。仓库里有的是：
场景数据、贴图索引、以及转换工具。

要用真实的《大洋落日》模组：

1. 从 Steam 创意工坊订阅该模组（Workshop ID `3636541733`）
2. 把模组的资产包放到项目根目录，命名 `大洋落日_资产.zip`
3. 跑管线：

```bash
python3 -m pip install pillow
python3 tools/build_assets.py        # 约 10 秒
```

产出 1003 张 WebP（198.8MB → 13.1MB，压到 6.6%）到 `public/assets/`。

**用别的模组？** `tools/build_assets.py` 里的输入路径与 `manifest` 解析
是按这个模组写的。换成别的模组需要改脚本 —— 欢迎提 PR。

不用真实资产也能玩：直接用内置的**骰子和标记**（工具栏「物品」），
它们不依赖任何贴图。

## 操作

| 动作 | 触屏 | 鼠标 |
|---|---|---|
| 选中 / 移动 | 点击 / 直接拖动 | 同左 |
| 选中被压住的棋子 | 同一处**重复点击**依次往下选 | 同左 |
| 框选 | 工具栏「框选」+ 拖空白 | **Shift + 拖空白** |
| 平移地图 | 单指拖空白 | 拖空白 |
| 缩放 | 双指捏合 | 滚轮 |
| **棋子菜单** | **长按棋子** | **右键** |
| 加选 / 减选 | 框选 | Shift + 点击 |
| 全选 / 取消 | 工具栏按钮 | `Ctrl/Cmd+A` / `Esc` |
| 微调位置 | — | 方向键（`Shift` = 10 倍） |
| 放骰子 / 标记 | 「物品」→ **拖到桌面** | 同左（直接点则放在视图中心） |

**快捷键**：`f` 翻面（选中骰子时 = 掷骰）、`r` 旋转 90°、`0` 回原点、
`Delete` 删除、双击空白处 = 适配全部棋子。

**工具栏只有四项**：框选 / 物品 / 原点 / 设置。存读档在「设置」里。

## 双盲

房主在工具栏点「**视野区**」，拖一个矩形，选「哪支队伍能看见」和遮挡方式：

| 模式 | 没被授权的队伍 |
|---|---|
| **看不见** | 完全不知道这块区域存在（连框都看不到） |
| **看得见背面** | 看得见有东西在这，但只能看到棋背 |

**这是服务端裁剪的**，不是前端把图片藏起来 —— 打开 F12 也看不到。

> ⚠️ **它是「防误看」，不是「防作弊」。**
> 本项目没有账号体系：知道邀请码就能进房间，
> 没有 HTTPS 时身份 token 在局域网里可被嗅探。
> 想用来防作弊请自己加一层（反代 + HTTPS + 访问控制）。

队伍有四支：`未入座`（新人默认，**两边都看不到**）、`红方`、`蓝方`、
`旁观`（上帝视角，全都能看到）。**队伍只能由房主分配**。

## 环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `PORT` | `3000` | 监听端口 |
| `HOST` | `0.0.0.0` | 监听地址 |
| `DATA_DIR` | `./data` | 数据目录（房间与盘面快照） |
| `BOARD_IDLE_MS` | `600000` | 盘面在内存里保留多久没人就卸载（10 分钟） |
| `BOARD_GC_INTERVAL_MS` | `60000` | 内存回收的检查间隔 |

```bash
PORT=8080 DATA_DIR=/srv/tabletop npm start
```

有一个健康检查端点：`GET /api/health`。

## 技术取向

针对**极弱设备 + 很差的自建服务器**做的工程减负：

**客户端** —— 不用 DOM、不用 3D 引擎。双层 Canvas：
底层（原点准星、视野区框）只在视变换变化时重画，顶层按需重绘。
**无常驻 rAF 循环**（空转会让手机持续唤醒）。
1003 张贴图全解码要 290MB，靠 LOD 色块 + 按**字节**预算的 LRU
压到最坏 65MB。

**服务端** —— 只有 `ws` 一个依赖。纯中继：
分配序号与层叠序、维护权威副本、广播。不做规则判定。
op 是绝对赋值 + 服务端串行分配 `seq`，所以**不需要 OT / CRDT / 回滚**。
磁盘落盘 5 秒防抖 —— **挂机不写盘**，只有真有人操作才写。
静态响应开 gzip（场景 JSON 省 83%）、带 ETag（刷新走 304，0 字节）。

## 已知限制

- **没有账号体系**：邀请码就是入场券。防的是「不知道码进不来」，不是「无法伪造身份」
- **没有 HTTPS**：需要的话在反代层加（见 `DOCKER.md` 的可选 Caddy 服务）
- **`/api/save` 导出全量盘面**（含看不见的棋子与视野区），已收敛为**仅房主**可调
- **房主能看到一切**（他是「合法」的上帝视角）—— 权限模型的固有性质，不是漏洞
- **视野区只支持矩形**，且一个区域只能授权一个队伍
- **任何在场玩家都能操作任何棋子**：盘面操作不校验归属。「只能动自己的棋」属于规则判定，与"纯沙盒"定位冲突
- **删除不可撤销**（有二次确认，没有 undo 栈）
- **消息流不存历史**：中途加入的人看不到刚才发生了什么
- **无断线增量补发**：重连直接拉全量快照
- **重叠处没有「列出所有棋子让我挑」的浮层**，靠重复点击循环
- **单条消息上限 1MB**：一批 778 枚约 26KB，够用
- **无限地图没有边界保护**：拖到 1e15 这种量级浮点精度会退化
- **3D 对象已跳过**：`Custom_Model`、`FogOfWarTrigger`、`Custom_PDF` 等
  降维不可逆，与本版目标无关

## 开发

**改代码前请先读 [agent.md](agent.md)** —— 那里写了不变量、
踩过的坑、以及「看起来多余但删了会静默出错」的写法。

项目是**零构建**的：原生 `<script>` 标签，无打包器、无框架。
改完文件刷新浏览器即可（改服务端要重启）。

```
server/    Node http + ws（唯一依赖）
public/    原生 IIFE 脚本 + 双层 Canvas
tools/     资产管线（Python + Pillow）
```

`readme.md`（本文）是给使用者的；`agent.md` 是给改造者的。
